# Business Card Project

## Overview
This is a personal project created to showcase my frontend development skills.  
The project focuses on building a simple yet elegant business card using **HTML** and **CSS**.

It demonstrates my ability to design responsive layouts, apply styling, and use modern CSS techniques to create visually appealing web components.

## Features
- Fully responsive design suitable for different screen sizes  
- Clean and professional layout  
- Custom fonts, colors, flexbox, and styling using CSS  
- Display of personal/contact information in a visually appealing manner  

## Technology Stack
- **HTML**: Structure and semantic markup  
- **CSS**: Styling, layout, colors, and responsive design
